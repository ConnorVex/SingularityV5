Don't want to roll for a listed style? **Create your own!** Pick a type and follow its rules.

<KeyFacts items={[
  { label: 'Types', value: "Flow or Moveset" },
  { label: 'Moveset moves', value: "4" },
  { label: 'Passives', value: "Permission Based" },
]} />

<CardGrid>
  <Card title="Flow Type" icon="pencil">
    Must have:
    - **Special requirements**
    - A **proper explanation** of how it works

    No moveset, and it **can't** be combined with the Moveset class. Instead it gives you another way to fight with what you already know.

    With **permission**, it can include **one special move**.
  </Card>
  <Card title="Moveset Type" icon="pencil">
    Must have:
    - **4 moves**
    - A **cooldown** for each move

    For an **Ultimate**, also add:
    - **4 Ultimate moves**, with cooldowns
    - **How** the user gains the Ultimate

    Can be combined with a [Weapon style](/fighting-styles/weapon-styles/) for a powerful moveset.
  </Card>
</CardGrid>

:::caution[Passives are Permission Based]
Passives can be pretty busted, so they need **permission**.
:::
