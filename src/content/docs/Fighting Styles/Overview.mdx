**Fighting Styles** are combat systems that help you in battle. Not everyone is born with powers, and Fighting Styles help **even the odds** by adding a new twist to **combat-based roleplay**. A style can be **hand to hand** or **weapon based**.

You don't need to start with one: you can learn any style **in universe** if you find a teacher willing to teach you.

## Gaining a Fighting Style

<CardGrid>
  <Card title="In-Roleplay Teaching" icon="open-book">
    Find a teacher in universe who's willing to train you.
  </Card>
  <Card title="Rolling for One" icon="random">
    Request a roll in the [Singularity Rolling Channel](https://discord.com/channels/1180269616652619807/1278456694460121191). If the style needs Physical Stats, you're placed in its tier.
  </Card>
  <Card title="Clans" icon="puzzle">
    Join a Clan that teaches one.
  </Card>
</CardGrid>

:::caution[Rolls are final]
Once rolled, you **keep that Fighting Style** no matter what.
:::
