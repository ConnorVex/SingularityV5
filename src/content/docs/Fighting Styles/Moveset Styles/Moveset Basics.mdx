Moveset styles come with a **set list of moves** that **can't be altered**, which makes them a bit rigid. In exchange, they unlock **Ultimate Modes**.

<CardGrid>
  <Card title="One attack per turn" icon="warning">
    You can only use **1** move per turn, unless a passive (like **Chaining**) says otherwise.
  </Card>
  <Card title="Ultimate Modes" icon="rocket">
    Meet the requirements to unlock a **new set of super powerful moves**. Some Ultimates last a **set number of turns**, others until a move is used. They're one of the **fastest ways to overwhelm** an opponent.
  </Card>
</CardGrid>
