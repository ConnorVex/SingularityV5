**Mangaka:** Atsushi Ohkubo

<CardGrid>
  <Card title="Key Points" icon="star">
    - Pyrokinetics are **the meta of fire abilities**, outclassing fire-based Quirks, abilities and Cursed Techniques
    - Some **techniques work for non-Pyrokinetics** too
    - Every Pyrokinetic follows **a theme** and sticks to it no matter what
    - Not just flame: Pyrokinetics extend into **plasma, thermodynamics** and more
    - The **only system** where **anyone** can become a Pyrokinetic **at random**
  </Card>
  <Card title="Getting Started" icon="pencil">
    **Second Generation**
    ```
    Generation: Second
    Pyrokinetic Manipulation: Level 0
    ```
    No special starting points.

    **Third Generation**
    ```
    Generation: Third
    Pyrokinetic Power: Level 0
    Oxygen Tank: Level 1
    Pyrokinetic Efficiency: Level 0
    Oxygen Absorption Rate: Level 0
    ```
    **8 Fire Force Tier Points (FFTP)** to spend. Each one raises a starting stat by **1 level** (e.g. Power Level 0 → 1).
  </Card>
</CardGrid>
