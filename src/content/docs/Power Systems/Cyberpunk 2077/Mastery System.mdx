An exclusive mastery system that **rewards choosing Cyberware over genetic abilities**.

:::danger[Powerless only]
You must have **no powers** and **never gain any**. If you ever develop powers, **everything** from this system is **forfeit** and it's **locked permanently** for that character.
:::

<CardGrid>
  <Card title="XP Bar" icon="rocket">
    Appears with the **V Build** or when you go powerless. **Max level: 100**, and it gets harder as you go.

    | Earn XP by | XP |
    |--|--|
    | Using Cyberware in combat | 10 per session |
    | Killing with Cyberware *(OC/Canon only)* | 15 per kill |
    | Fixer gigs | Varies (hundreds to thousands) |
    | Random encounters | Varies |

    Each level needs **1.5×** the XP of the last: 100 → 150 → 225 → 337…
  </Card>
  <Card title="Skill Points" icon="star">
    - **+4 Skill Points** every level up
    - **Every** Skill Tree upgrade costs **1 point**
    - Unlock perks to help you survive as a powerless character, including extra [Cyberware slots](/SingularityV5/power-systems/cyberpunk-2077/cyberware/)
  </Card>
</CardGrid>

:::note[Skill tree coming soon]
The Cyberpunk Skill Tree hasn't been moved over yet.
:::
